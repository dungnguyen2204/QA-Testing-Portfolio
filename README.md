## 📂 Project 1: E-Commerce Web Application (Shopee Clone)
**Role:** Manual Tester | **Type:** Personal Project
**Tools:** Microsoft Excel, Jira Cloud, Chrome DevTools.

### 📝 Overview
Conducted comprehensive manual testing for core e-commerce modules including **Authentication, Search, and Shopping Cart**.

### 🎯 Key Highlights:
* **Test Design:** Authored **37 detailed Test Cases** applying Equivalence Partitioning (EP) and Boundary Value Analysis (BVA).
* **Test Scope:** Executed Functional Testing, UI/UX Testing, Accessibility (Keyboard navigation), and basic Security Testing (XSS Injection).
* **Bug Tracking:** Logged, tracked, and managed bugs using **Jira Cloud** with structured Bug Reports (Steps to reproduce, Expected/Actual results, Severity/Priority).
* **Debugging:** Utilized Chrome DevTools to isolate UI layout issues and extract visual evidence.

> 📁 **Explore this project:** Check out the `1_Shopee_Manual_Testing` folder for the Test Design Excel file and Jira Kanban Board/Bug evidence screenshots.

## 📂 Project 2: E-Commerce API Testing (DummyJSON)
**Role:** API Tester | **Type:** Personal Project
**Tools:** Postman.

### 📝 Overview
Performed manual API testing for backend logic using the open-source DummyJSON system, focusing on Auth, Products, and Cart endpoints.

### 🎯 Key Highlights:
* **API Interactions:** Tested various HTTP methods (`GET`, `POST`, `PUT`, `DELETE`) to validate business logic.
* **Data Validation:** Verified endpoint responses, including Status Codes, Response Times, and JSON Data structures.
* **Environment Variables:** Implemented Postman environments to handle dynamic data streams (e.g., extracting Bearer Tokens from Login API for subsequent requests).
* **Workspace Organization:** Structured test cases logically within Postman Collections for maintainability.

> 📁 **Explore this project:** Check out the `2_DummyJSON_API_Testing` folder for the exported Postman Collection and Environment files.
